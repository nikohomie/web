Instrucciones de Instalación

  1. Java JDK: Instala primero el JDK. Durante la instalación, asegúrate de configurar la variable de entorno JAVA_HOME.
  2. IntelliJ IDEA: Instala el IDE. Es recomendable usar la versión Community que es gratuita y completa.
  3. Maven: Descomprime Maven en una carpeta y agrega la carpeta bin a tu PATH del sistema.
  4. Spring Boot CLI: Descomprime y agrega al PATH. Verifica con el comando: spring --version
  5. PostgreSQL: Instala la base de datos. Anota el usuario y contraseña que configures durante la instalación.
  6. Postman: Instala Postman para probar las APIs que desarrollaremos.

Importante

Asegúrate de descargar e instalar todos los componentes antes de comenzar la capacitación. Si tienes problemas con alguna instalación, contacta al instructor.
